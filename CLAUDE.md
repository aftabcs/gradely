# Project

Single-page static website (`index.html`) hosted on **GitHub Pages**.

- Repo: `aftabcs/gradely` (remote `origin`, HTTPS)
- Branch: `main` — pushing to `main` publishes the live site
- No build step, no framework, no dependencies. Edit `index.html` directly.

# Workflow

- Use the **git CLI** for all version control and GitHub operations (commit, push, branches, PRs via `gh`). Don't ask about VCS approach — this is settled.
- Since `main` is the published branch, only commit/push when explicitly asked.
